# Handoff checklist

1. Supply photos (`docs/SHOT-LIST.md`), run `npm run images`, fill each slot's credit/date/press flag.
2. Resolve every `[[TO CONFIRM]]` (grep the repo; see PROGRESS.md and `docs/CONTENT-NEEDED.md`).
3. Re-verify sources flagged `verified: false` in `data/sources.ts`, then flip the flag.
4. Senator signs off the commitments and the letter; flip commitments from DRAFT only on written approval.
5. Native Kiswahili review of the lines listed in PROGRESS.md.
6. Confirm election facts on iebc.or.ke (date, polls close, key dates, verification link).
7. Set environment variables and deploy to Vercel (README).
